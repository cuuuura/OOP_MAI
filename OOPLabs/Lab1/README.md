# Лабораторная работа №1
Необходимо реализовать 3 класса, сделав из них корректную иерархию наследованная (1 -> 2 -> 3). \
Каждый класс должен содержать: \

не менее 3 собственных атрибутов класса \
не менее 3 собственных методов класса \

Описание геттеров и их сеттеров обязательно и не входит в количество методов. \
Иерархия должна быть реализована вокруг заданного класса (найдите свой номер в группе). \
Заданный класс может занимать любое место в иерархии (как 1, так и 2, и 3). \
Иерархия должна быть полностью корректна логически. \
